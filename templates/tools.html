Supported conversions

What File Forge does

ISO→GOD

ISO to Games on Demand

Converts a supported Xbox or Xbox 360 ISO into a GOD package. Multi-disc sets are detected and kept in separate disc folders.

XEX→GOD

XEX folder to Games on Demand

Packages an extracted game folder containing default.xex as unsigned GOD content. Available Xbox 360 title artwork is copied into the package.

GOD→XEX

Games on Demand to XEX folder

Checks and extracts a GOD package into normal game files. Related multi-disc packages stored together are grouped automatically.

How it works

A short, repeatable process

  1. 1
    Choose a mode

    Select ISO → GOD, XEX → GOD, or GOD → XEX.

  2. 2
    Add files

    Add a single item or build a queue.

  3. 3
    Choose an output folder

    File Forge keeps GOD and XEX output separated.

  4. 4
    Convert

    Each job completes required format checks before it is marked finished.

Checks and safeguards

Checks that stay out of the way

  • Reads source files without modifying them.
  • Refuses to merge into a nonempty output folder.
  • Refreshes available destination capacity every five seconds and checks required space again before writing.
  • Keeps required GOD structure, header, part-size, allocation, and XDVDFS checks active.
  • Optional full input and finished-output verification can be disabled for faster conversions, especially on HDDs. Skipping it means File Forge cannot fully verify every source or output byte.
  • Removes incomplete failed output by default, or retains it when troubleshooting is enabled.

Options

Set it once

File Forge can remember separate starting folders for ISO images, GOD packages, and XEX game folders. Leave any folder unset and the normal File Explorer location is used.

Output

Keep destinations separate

Choose independent default locations for generated GOD packages and extracted XEX folders. Applied settings remain available the next time File Forge starts, and Restore returns the recommended checks and cleanup behavior.
